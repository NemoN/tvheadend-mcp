# Tool reference

Generated from the registered Python methods. Do not edit this file by hand.
Run `uv run python scripts/generate_tool_reference.py` after tool changes.

29 read tools and 24 write tools are registered.
Write tools accept `dry_run`; normal calls execute unless documented otherwise.
`TVH_READ_ONLY=true` blocks writes while permitting reads and previews.
UUIDs, class names, field IDs and options must come from the connected server.

API paths are relative without '/api/'; pagination can be supplied in parameters.

## `tvh_apply_maintenance_plan`

**Write.**

```python
tvh_apply_maintenance_plan(plan_id: str, dry_run: bool = True) -> dict[str, typing.Any]
```

Apply a reviewed plan from this MCP process; previews by default.

Plans expire after 15 minutes and actual executions consume the ID. Invented,
expired or stale plans are rejected. Rechecks inventory and node fields, refuses
active inputs/subscriptions, and attempts guarded rollback on a partial failure.
Keep the returned recovery_snapshot; this is not an atomic transaction/full backup.

## `tvh_probe_reception`

**Write.**

```python
tvh_probe_reception(service_uuid: str, duration_seconds: int = 10, max_bytes: int = 16777216, tuner_uuid: str | None = None, dry_run: bool = True) -> dict[str, typing.Any]
```

Preview or run a bounded service MPEG-TS test (1..30 seconds, at most 64 MiB).

Without tuner_uuid, Tvheadend selects the receiver. An explicit frontend UUID
temporarily isolates that tuner by disabling all competing enabled frontends.
Isolation requires an idle server/no imminent DVR, journals prior settings and
restores them on completion, error or cancellation. Save the preview snapshot.
Process/host crashes require inspection via reception_recoveries and explicit restore.
Active probing is blocked in read-only mode, including GET-only stream tests.

## `tvh_update_node`

**Write.**

```python
tvh_update_node(uuid: str, settings: dict[str, typing.Any], dry_run: bool = False) -> dict[str, typing.Any]
```

Update any API-exposed tuner, LNB, DiSEqC, Unicable, network, mux, service,
channel, EPG, bouquet or DVR object. Inspect get_node/get_field_options first.

Uses actual field IDs and native units, validates unknown/read-only fields,
preserves unspecified fields; arrays REPLACE existing arrays. dry_run previews.
After satconf/lnb_type/switch_type/en50494_type changes, re-read hardware_tree:
child nodes may have been recreated. No hard-coded limits on expert settings.
