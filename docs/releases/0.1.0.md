Initial public release of Tvheadend MCP.

39 tools cover DVR, EPG and the DVB configuration exposed by Tvheadend's API:
tuners, satellite child nodes including Unicable/JESS, networks, muxes, native
scans, service mapping and channels. Includes dynamic schemas, read-only mode,
dry-run previews and selected-object snapshots.

Start with the [README](https://github.com/NemoN/tvheadend-mcp#readme),
[German guide](https://github.com/NemoN/tvheadend-mcp/blob/v0.1.0/README.de.md),
or [tool reference](https://github.com/NemoN/tvheadend-mcp/blob/v0.1.0/docs/tools.md).

```bash
uvx --from git+https://github.com/NemoN/tvheadend-mcp.git@v0.1.0 \
  tvheadend-mcp --env-file /absolute/path/tvheadend.env
```

Requires Python 3.11+ and a reachable Tvheadend installation with suitable API
permissions. Development targets Tvheadend 4.3; available features depend on the
connected build and hardware. The example env file starts in read-only mode.

The wheel and source archive are attached with SHA-256 checksums. No PyPI package
or prebuilt container image is published by this release. Snapshots are selected
settings only and do not replace a complete Tvheadend backup.
