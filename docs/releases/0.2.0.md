Tvheadend MCP 0.2.0 adds 14 tools, bringing the total to 53.

- **EPG:** global settings and schedules, installed-module control, source mapping,
  native OTA/internal triggers, and coverage/gap reports with description counts.
- **Reception:** bounded MPEG-TS/media-packet checks, signal units and counter
  deltas; optional explicit tuner isolation with idle/DVR checks and private
  recovery journals.
- **Maintenance:** duplicate/HD-SD audits, reviewed channel merges and network
  consolidation using broadcast IDs. Retained channels keep their UUIDs; source
  objects are disabled rather than deleted.
- **Change control:** expiring plan IDs, inventory/readback checks and guarded
  rollback. Probes and maintenance execution preview by default.

Read the [operations guide](https://github.com/NemoN/tvheadend-mcp/blob/v0.2.0/docs/operations.md)
before using tuner isolation or maintenance. Keep a complete configuration backup
and the reviewed recovery snapshot. Crash recovery is explicit; operations are
not atomic across Tvheadend clients.

```bash
uvx --from git+https://github.com/NemoN/tvheadend-mcp.git@v0.2.0 \
  tvheadend-mcp --env-file /absolute/path/tvheadend.env
```

Requires Python 3.11+ and a Tvheadend build exposing the corresponding APIs.
Reception tests also require advanced streaming rights and the `pass` profile.
External XMLTV socket feeds and host-level backup/administration remain outside
this release. No audio/video decoder, PyPI publication or prebuilt container
image is included.
